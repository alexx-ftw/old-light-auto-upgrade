- `docs/reinforcement-map.js`: the private pending marker contains every scalar consumed by projection/inverse projection: galaxy, camera x/y, zoom, sine/cosine tilt, perspective distance, base focal length, CSS rectangle, and native logical dimensions. Scheduling metadata and counters do not affect those inputs. The schematic already had a narrower visual signature and did not need an implementation change.

## Native UI layering review

The supplied screenshot was inspected. It shows a cyan arrow visibly covering an opaque upper game panel. Clipping only to the canvas rectangle cannot fix this when the canvas extends behind the native UI. No arbitrary top-margin exclusion was introduced.

The separately verified native facts supplied by the release owner are: `#app` contains an unpositioned canvas followed by `header#hud`; the HUD is absolute with automatic z-index; other ordinary UI includes positive z-indices; relevant ancestors are transform-free. Native CSS asset: `galaxy-CxbOuUuE.css`, SHA-256 `78530401c5f054a7d00bc167f2e98c1339bcbc2354903b10a1a1f5c91dae1e30`.

The reviewed change places the fixed, zero-z-index SVG immediately after the canvas and before the later HUD. This leaves it above canvas painting and below the verified native UI. No native styles are changed. Inline pointer exclusion and viewport geometry remain intact even when the Helper panel is mounted elsewhere. Missing, detached or uninsertable anchors hide the overlay instead of falling back to a high body-level layer.

Placement is checked before the unchanged-geometry cache return. Correct placement performs no insertion; misplaced, detached or remounted layers are repaired without rebuilding unchanged line nodes. These properties address both lifecycle safety and the original flicker concern.

Added layer tests:

1. `layer review: overlay is the immediate zero-layer canvas sibling before native HUD`
2. `layer review: stable renders and metadata refresh perform no layer reorder`
3. `layer review: reordered or detached SVG is repaired before unchanged-geometry cache return`

5. `layer review: missing, disconnected and uninsertable anchors hide arrows and recover safely`
6. `layer review: Helper panel mount location never becomes the arrow layering parent`

The layer fixture checks DOM ordering, inline styles, pointer exclusion, native-style preservation, lifecycle recovery and node identity. It is not a browser paint test. No browser was launched for this review, in accordance with the requested environment constraint.
