# Contrato de stderr de Node probado con el CLI real

Mejora exclusiva de cobertura sobre main b0ed4761badbfbf99a9304ab1ad32ffc7b972109. No cambia código productivo, parser, deadlines, permisos, telemetría ni bytes/versión1.17.28 del userscript. La política de release permite conservar versión cuando solo cambian pruebas/documentación.

La revisión anterior había identificado como posible límite que dos resúmenes juntos o un resumen partido se perdieran al parsear un único evento. Antes de introducir un parser nuevo, se reprodujo el transporte mediante fixture del CLI real: el test de Node escribe dos resúmenes con una sola llamada, luego un tercero en dos llamadas separadas20ms. El validador original b0ed476 ya conserva los tres. El experimento no reproduce un defecto de producción: Node24 normaliza las líneas en esta ruta. Se retiró el cambio de parser que carecía de evidencia necesaria. No se inventa un beforeFail para justificarlo.

La nueva regresión tests/release-validation.test.cjs, nombre gate preserves grouped and fragmented browser summaries without accepting oversized incomplete or secret stderr, añade un contrato de integración antes ausente: tres mensajes válidos retenidos en orden, campos extra privados sintéticos omitidos, línea sobredimensionada descartada, mensaje válido posterior recuperado y JSON final incompleto no expuesto. El CLI termina con éxito real solo cuando todas las pruebas de la fixture pasan; la aceptación sigue validando sus resúmenes estructurados. Los diagnósticos por sí solos no dan crédito de test.

El mismo test copiado junto al validate-release.cjs exacto de b0ed476 pasó antes de cualquier cambio en código. Evidencia externa browser-summary-stream-before.tap. Un parser de buffering experimental también pasó; no aportó mejora demostrada y se eliminó. La versión final conserva únicamente la prueba y documentación, y enlaza el caso en el feedback histórico del resumen sanitizado sin alterar su reproducción original.

Comando dirigido de experimento: node --test --test-name-pattern='gate preserves grouped' /workspace/oldlight-transfer/browser-summary-stream-before/tests/release-validation.test.cjs. No sustituye el gate completo del commit final limpio ni su revisión independiente. Se comprobará que userscript y metadata son idénticos a b0ed476, y se verificarán commit/árbol/padre, CI y archivos servidos después del push normal.

Límites: observado Node24/Linux y CLI real; no se garantiza fragmentación equivalente en cada versión, plataforma o consumidor alternativo del reporter.
