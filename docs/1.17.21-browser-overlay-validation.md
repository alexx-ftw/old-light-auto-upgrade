No se cuenta una vuelta ni rAF solicitado como callback ejecutado.

El archivo *.test.cjs se inventaría y ejecuta en validate-release.cjs como el resto; nunca se convierte en *.browser.cjs opcional excluido. Sin Chromium y sin exigencia, informa BROWSER_UNAVAILABLE y el preflight declara executable:null: no acredita render. `OVERLAY_BROWSER_REQUIRED=1 env -u NODE_PATH node validate-release.cjs --report /ruta/nueva.json` exige navegador. El nuevo workflow .github/workflows/offline-browser.yml ejecuta el gate completo con esa exigencia y sube solo PNG, frames.json y reporte, no perfiles. No amplía permisos: contents:read.
