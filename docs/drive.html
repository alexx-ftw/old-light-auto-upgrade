Configuración avanzada

Si la conexión ya está configurada, basta con iniciar sesión. Estas opciones permiten emplear tu propio proyecto de Google o volver a acceder a sus copias anteriores.

Al escribir se guarda el borrador. Se aplica cuando el Client ID esté completo.

Cambiar el proyecto de Google puede cambiar las copias que ves. Conserva tu Client ID anterior para volver a acceder a sus copias.

  1. Activa Google Drive API en tu proyecto.
  2. Configura el consentimiento OAuth. Si está en pruebas, añade tu cuenta como usuario de prueba.
  3. Crea un cliente OAuth de tipo Aplicación web con este origen JavaScript autorizado:
https://alexx-ftw.github.io

Del JSON solo se conserva el Client ID. El client secret no se utiliza ni se guarda. Vaciar el campo conserva la conexión; usa Borrar Client ID para eliminarla.

Cuenta y permisos

Esta preferencia se guarda automáticamente.

Desconectar cierra esta sesión. Retirar el permiso revoca el acceso concedido a esta aplicación en Google.

¿Retirar el permiso de esta aplicación? Para volver a usar las copias tendrás que autorizarla de nuevo.

El token temporal se conserva en almacenamiento privado de Violentmonkey hasta caducar o desconectar. No se incluye en las exportaciones, copias, métricas ni sincronización del Helper. No está cifrado por el Helper y una exportación completa del gestor puede incluirlo; desconecta antes de compartirla. No se guarda un refresh token ni se renueva sin un clic.
