- Observador productivo y ownerReader: censos positivos, caducidad, publicación pendiente y revocación/reentrada de caché. No se inventa ID histórico cuando el reporte solo contiene nombre.
- Chromium real, ShadowRoot/CSS y panel/controlador/cola/runtime de navegación productivos: autorización/confirmación denegadas, controles dentro de 320/665px; Send → tránsito bloquea ataque → censo de llegada → una incursión → Victory sin captura → flota insuficiente espera → censo repone → segunda incursión → captura detiene. Adaptador y mundo son sintéticos. Reloj avanza 2s al cambiar censo para ejercer el throttle de navegación; no es una ETA.
- Suite completa y builders deben ejecutarse sobre el commit final limpio con navegador obligatorio. Su resultado, hashes, CI y revisión exacta se conservan fuera del checkout; las pruebas parciales anteriores no sustituyen ese gate.

## Gaps y otras superficies

No hay partida, órdenes reales, sesión autenticada ni garantía sobre resultados de combate; no se probó el diálogo nativo real de creación de campaña (la confirmación se modela con true/false). El navegador prueba pintura y geometría de esta UI, no toda interacción posible. El observador no consume respuestas de regiones; destinos sin propiedad positiva pueden permanecer esperando. No existe fórmula de combate ni ETA de flota mixta comprobadas.

Drive no sincroniza objetivos ni autorizaciones GM locales. Las preferencias no contienen estos intents. Las copias completas mantienen el contrato de cola: trabajos importados pausados, sin objetivo matching no son activables; los clientes anteriores pueden rechazar el nuevo owner en una copia completa. No se cambia esquema de preferencias/journals. Sustituir cola no autoriza repetir un envío desaparecido. La regresión con cola productiva `importing an empty production queue after acceptance before reconciliation never dispatches the same conquest claim twice` falla sobre draft2 con 2 aceptaciones en vez de 1, usando el mismo harness y QA_CONQUEST_CONTROLLER_SOURCE; pasa con el módulo final. El applyBackup manual completo sustituye cola; applySyncedBackup de preferencias Drive no la sustituye. No se atribuye este defecto a sincronización Drive. Importar durante navegación propia de conquista está bloqueado. Todas las guardas de créditos, aliados, coordinación y confirmación nativa siguen en la frontera de misión existente.
