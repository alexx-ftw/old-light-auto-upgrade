## Cambio e invariantes

Si todos los almacenes se restauran, se conservan los bytes exactos previos y su activación. Si algún rollback falla, se pone enabledfalse en memoria antes de reconstruir UI y se intenta suspender el controlador imperial. Un fallo de suspend no impide guardar la pausa global. Esa pausa basta como guarda exterior de operaciones ordinarias e imperiales; no se cambian objetivos ni preferencias imperiales como supuesto arreglo del almacén que falló.

El guardado conserva el objeto JSON anterior y sus campos desconocidos, cambiando únicamente enabled a false. Si los bytes anteriores están ausentes o son inválidos, utiliza las preferencias válidas en memoria. Se relee el texto exacto recién escrito para no confundir no-op con pausa durable. Si escribir o releer falla, se mantiene la pausa de sesión y el mensaje advierte que no se pudo confirmar el guardado y que hay que revisar almacenamiento antes de recargar. No se llama settingsChanged con estado mixto y no se presenta el backup como restaurado.

La pausa precede restoreNumericInputs/syncSettingsTabs/layoutHelper: que fallen no permite saltársela. El finally conserva la liberación de importingBackup y programación existentes. Un fallo UI o cleanup aún puede reemplazar el error exterior; el stop ya se establece antes. No se afirma que todos los callbacks del host sean infalibles.

## Controles

- Rollback incompleto con almacenamiento sano: paused en memoria, bytes y readSettings tras recarga, preferencias anteriores conservadas.
- Rollback completo e importación correcta: comportamiento legítimo y notificación de cambio solo en éxito.
- Escritura ignorada, excepción y lectura de verificación fallida: advertencia de pausa solo en sesión.
- Render o suspend fallidos: la pausa se establece previamente y no queda importingBackup activo.
- Settings ausentes y campos futuros desconocidos: persistencia de pausa sin perder los valores anteriores.
- Schema futuro y enabled importado malformado: rechazo antes de escribir, cancelar o aplicar configuraciones.
