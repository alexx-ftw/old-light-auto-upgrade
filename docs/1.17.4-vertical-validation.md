# 1.17.4: altura disponible del panel

## Observación y cambio acotado

La captura aportada el 15 de octubre de 2026 (1566 × 1297 píxeles) muestra el panel entre aproximadamente y=93 e y=991, con contenido desplazable y unos 300 píxeles libres debajo. La fuente 1.17.3 limita la altura a 720 píxeles CSS. La escala exacta del navegador del usuario no se verificó; la captura es compatible con ese límite ampliado. No se atribuye ningún fallo de rutas, cámara o envíos a esta observación.

Base local: `6e40e25c0c589deb353f01d8c51f1c673bdce07f`, árbol equivalente a la publicación `d277c729853a9ea38b8d03b57226baadf2013268`.

Se elimina el límite fijo y se usa `100dvh` menos el anclaje superior y 12 píxeles de margen inferior. Sin posición guardada, ambos márgenes son de 12 píxeles. El anclaje superior se conserva salvo que deje menos de 360 píxeles de panel; en ventanas menores se adapta al espacio completo disponible. Minimizado conserva su altura automática y movilidad. No se añade una preferencia persistida ni se modifica la automatización, rutas, almacenamiento, permisos o sincronización.

## Reproducción previa y comprobaciones

Comando: `node --test tests/helper-vertical-space.test.cjs`.

El caso `expanded shell uses available viewport height instead of the fixed 720px ceiling` falla sobre la fuente base con el mismo archivo de test: la CSS contiene `height:min(720px,calc(100dvh - 24px))` en vez de altura adaptable al anclaje. Este caso prueba el contrato de CSS, no mide píxeles renderizados. Los otros casos ejecutan `layoutHelper` productivo con geometría simulada que responde al nuevo offset; sus fallos en la base no se presentan como mediciones del navegador anterior.

| Flujo | Resultado comprobado offline |
| --- | --- |
| Anclaje 74 px, viewport 1038 px | Offset 74 px, altura simulada 952 px, margen inferior 12 px |
| Restablecer posición | Offset vuelve a 12 px y se limpian coordenadas inline |
| Ventana de 400/280 px | Anclaje limitado; cuerpo expandido de 360/256 px |
| Minimizado cerca del fondo | Cabecera compacta sigue móvil; restauración recupera 360 px |
| Arrastre y layout repetido | Offset actualizado, sin deriva tras 20 repeticiones |
| Aumentar viewport | Crece la altura sin cambiar anclaje superior |

El archivo opcional `tests/helper-vertical-space.browser.cjs` prepara el HTML, CSS, lógica de anclaje y panel de rutas productivos en una página aislada. Permite una futura ejecución con `CAMOUFOX_PATH=/ruta/al/ejecutable node tests/helper-vertical-space.browser.cjs`. Incluye pantallas altas y pequeñas, cancelación de arrastre, minimizar/restaurar y pie visible. Su sintaxis se comprueba en el gate; **no se ha ejecutado satisfactoriamente** y no cuenta como QA aprobada.
